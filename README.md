# 本地转发网关
解决claude code新版校验模型名称导致无法连接到国产大模型的问题  
运行端口可以自己在源码里面修改  
模型名称和base url地址可以修改成其他任何平台。  
理论上修改源码中的api网关地址和对应的模型名称，它可以转发到任意一家国产大模型？？？（但是我没测试过，所以说是理论上。）  
所有文件都是claude code源码版对接deepseek-v4-pro编写的，我只是把我想要实现的功能告诉给它。并且我本地测试完全没问题，甚至你可以把js版直接仍在网站上远程使用。  
所以，如果源码在你本地起了什么奇怪的反应导致出现问题，不要来找我，我只是分享一下。
  
  
  
claude code配置界面填写规范：  
baseurl填写：127.0.0.1：你在源码中设置的端口  
apikey填写：你对应平台的key  
添加模型是模型名称填写：符合claude code检验的名称就可以了，本地网关会自动替换为deepseek-v4-pro
